Preguntas

Lo que todo el mundo pregunta antes de instalar.

¿Es gratis? ¿De verdad de verdad?

Sí. Código abierto con licencia MIT, sin anuncios, sin cuentas obligatorias, sin "versión premium".

¿Necesito Minecraft comprado?

Puedes jugar con cuenta Microsoft si lo has comprado (el launcher lo verifica), o crear un perfil offline para probar sin conexión.

¿Es seguro?

Sí: el código entero es visible en GitHub, los archivos del juego se verifican con SHA-1 contra los servidores de Mojang y nada se instala fuera de su carpeta de datos.

¿Funciona en Windows y Linux?

Sí: .msi y .exe para Windows; .AppImage, .deb y .rpm para Linux.
